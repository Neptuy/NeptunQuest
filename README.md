# NeptunQuest

Jeu d'entraînement au support informatique, en un seul fichier HTML (`index.html`).

## Contenu

- **Ticket mystère** : 67 tickets en 8 catégories (Réseau, Impression, Active Directory, Poste Windows, Messagerie & M365, Sécurité, Sauvegardes, Serveurs), 3 niveaux de difficulté, terminal simulé, indices, mode urgence, défi du jour, mode examen avec certificat, journée de support et parcours carrière.
- **Mini-jeux** : quiz chrono, phishing ou légitime, sous-réseaux et binaire, escape game.
- **Progression** : grades, succès, quêtes de la semaine, profil, fiche mémo des commandes.

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Fonctions réservées à la plateforme Claude

Le classement, les duels, les propositions de tickets, l'import de tickets et tout ce qui est généré par Claude (chat avec l'utilisateur, débrief, sorties de terminal simulées, tickets générés) utilisent les capacités de la page publiée sur claude.ai.
Hors de cette plateforme (fichier local, GitHub Pages), ces fonctions se désactivent d'elles-mêmes et le reste du jeu fonctionne, avec les scores enregistrés dans le navigateur.
